# TelCom-Churn-Analysis
## Overview
This project explores customer churn in the telecommunications sector. The goal is to identify drivers of churn, visualize patterns, and provide actionable insights that can help reduce customer attrition.

The repository contains business understanding, exploratory data analysis (EDA), and presentation materials to communicate findings effectively.

## Repository Structure
BUSINESS UNDERSTANDING REPORT.docx → Defines the problem, objectives, and business context.

Dataset Inspection Report.docx → Summarizes dataset quality checks and initial observations.

TelCom-EDA.ipynb → Jupyter Notebook with exploratory data analysis, visualizations, and churn driver exploration.

TelCom Presentation.pptx → Slide deck summarizing key findings and recommendations.

## Dataset
Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn/data

## Key Insights
Contract type and tenure are strong churn indicators.

High monthly charges correlate with increased churn.

Age was inspected but eliminated as a churn driver after deeper analysis.
